Ordner für Claude

Jede Fahrt landet zusätzlich als FIT- und JSON-Datei in einem Ordner auf diesem Laptop. Von dort kann Claude sie lesen. Die Dateien bleiben auf deinem Laptop.

Tipp: In „Dokumente“ einen neuen Ordner „Trainer-Fahrten“ anlegen und den wählen. Fragt Chrome nach, „Bei jedem Besuch erlauben“ anklicken.

Dieser Browser kann nicht in einen Ordner speichern. Bitte die App in Chrome oder Edge öffnen.

Strava

Einmal einrichten, dann landet jede gespeicherte Fahrt automatisch bei Strava.

  1. Auf strava.com/settings/api eine Anwendung anlegen. Name (Application Name): Trainer-App, Kategorie (Category): Training, Website: https://livelli.github.io, Callback-Domain (Authorization Callback Domain): livelli.github.io. Ein Logo (Icon) musst du hochladen, irgendein Bild genügt.
  2. Strava zeigt dir danach die Client-ID und das Client-Secret (beim Secret auf „Anzeigen“ klicken). Beide hier eintragen.
  3. Auf „Mit Strava verbinden“ klicken und bei Strava „Aktivitäten hochladen“ erlauben.

Die beiden Codes bleiben nur in diesem Browser auf deinem Laptop. Veröffentliche unter livelli.github.io keine fremden Seiten, die könnten sie sonst lesen.
